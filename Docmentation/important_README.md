# Shelf Life – Project Documentation

Welcome to the official documentation directory for **Shelf Life – Library Management System**.

This folder contains the project documents, design materials, development evidence, and supporting resources created throughout the development of our COMP229 – Web Application Development project.

## Documentation Contents

| Document | Description |
|---|---|
| Team Contract | Defines team roles, responsibilities, expectations, and collaboration guidelines. |
| Team Logo | Official Shelf Life project branding. |
| Wireframes | Initial visual designs and layouts of the application. |
| External Design Document (EDD) | Documents the application's interface design, features, and visual structure. |
| Application Screenshots | Visual evidence of implemented application features. |
| API Testing Evidence | Screenshots and results from backend API testing. |
| Presentation Materials | Slides and other materials prepared for the project demonstration. |
